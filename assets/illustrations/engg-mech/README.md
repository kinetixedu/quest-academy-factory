# Engineering Mechanical illustration library (engg-mech world, steel grey / safety orange)

Generated in Canva from text prompts (prompts.json), cut out with tools/cutout.py. Style rules: docs/ILLUSTRATIONS.md.
Plain light grey (#E9ECEF) background; `*-src.png` = original, plain `name.png` / `*-cut.png` = transparent cutouts for light cards (#F7F8FA).
Name labels are added in the video (pills), never baked into the image.
