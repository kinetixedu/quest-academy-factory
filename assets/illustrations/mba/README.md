# MBA illustration library (Boardroom world, navy / gold / cream)

Generated in Canva from text prompts (prompts.json), cut out with tools/cutout.py. Style rules: docs/ILLUSTRATIONS.md.
All images sit on a plain cream background; `*-cut.png` / plain `name.png` are transparent cutouts for white cards.
Name labels are added in the video (Poppins pill), never baked into the image.
