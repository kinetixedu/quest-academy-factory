# PUC illustration library (Lab Notebook world, shared by all five PUC subjects)

Owned by the PUC Physics session. Generated in Canva from text prompts (prompts.json, palette: ink navy #16213E, electric blue #2F6FEB, warm off-white #F7F5EF), cut out with tools/cutout.py. Style rules: docs/ILLUSTRATIONS.md.
Subject sessions reuse these files as they are; subject-only images go in this folder with the subject prefix (puc-physics-, puc-chemistry-, puc-maths-, puc-biology-, puc-electronics-) and a line in that subject's own section below.
Name labels are added in the video (Poppins pill), never baked into the image.
