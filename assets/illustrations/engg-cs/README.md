# engg-cs illustrations

Rules: docs/ILLUSTRATIONS.md. Prompts (style block + cast lines, reuse word for word): prompts.json.
engg-cs is a dark world: never place a cutout on the navy background. Show an image on a light plate card (#F4F1EA, radius 6). Faces (`-face.jpg`, 256x256) go in circles with a cyan ring.
Files per cast member: `-src.png` (Canva render 484x600), `-plate.png` (2x LANCZOS, full image for a plate card), `.png` (2x cutout via tools/cutout.py, for a figure placed on a plate), `-face.jpg`.
