# engg-electronics illustrations (prefix eece-) - Engineering Electronics series

Dark world (muted copper + soft PCB green, charcoal, warm greys): show each image whole on a light plate card (#F4F1EA), never cut out onto the dark background. `-cut.png` cutouts exist for the cast only if a light card ever needs them. Faces (`-face.jpg`, 256x256) go in circles. Prompts and Canva media ids: prompts.json. Style rules: docs/ILLUSTRATIONS.md.
Generated in Canva, pulled at working size via the scratch-design render (484x600 / 600x450), upscaled 2x LANCZOS: cast 968x1200, scenes 1200x900.
