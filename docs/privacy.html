Privacy Policy

Quest Academy Factory · Last updated: 19 October 2026

Quest Academy Factory ("the app", "we") is an internal tool operated by MR Quest Technologies, Marathahalli, Bengaluru, Karnataka, India. It publishes Quest Academy's own educational videos to Quest Academy's own YouTube channel. This policy explains what data the app accesses through YouTube API Services, how it is used, stored, shared and deleted.

1. YouTube API Services

The app uses YouTube API Services (the YouTube Data API v3). By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (www.google.com/policies/privacy).

2. Who uses the app

Only MR Quest Technologies staff, acting for the Quest Academy channel. The app has no public sign-up. The only Google account that authorises it is the owner of the Quest Academy channel, through Google OAuth 2.0.

3. Information the app accesses

With the scopes youtube.upload and youtube.force-ssl, the app uploads our videos, sets their thumbnails, uploads English captions, lists and creates playlists on our channel, adds our videos to those playlists, and checks that a video we uploaded still exists. It does not read comments, subscribers, analytics, watch history, or any other user's channel or data.

4. Information we store

  • An OAuth refresh token for the Quest Academy channel, kept as an encrypted secret in our build system and never shown in logs or shared.
  • For each video we upload: its YouTube video ID, URL, playlist name, upload time and scheduled publish time, so the app never uploads the same lesson twice.

We do not store personal information about viewers or any other users. The app sets no cookies and uses no tracking.

5. How we use the information

Only to publish and organise Quest Academy's own videos on Quest Academy's own channel. We do not use API data for advertising, profiling, analytics or any other purpose.

6. Sharing

We do not sell, rent or share API data with anyone. Data is sent only to Google/YouTube through YouTube API Services when the app uploads or updates our own videos.

7. Retention and deletion

  • Video records (IDs, URLs, schedules) are kept while the video is on our channel and deleted within 30 days after the video is removed from YouTube.
  • If authorisation is revoked, we delete the stored refresh token and all data obtained from YouTube API Services within 7 days.
  • To request deletion of any stored data, email info@mrts.solutions; we complete deletion within 7 days and confirm by email.

8. Revoking access

The channel owner can revoke the app's access at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the app can no longer access the channel.

9. Security

Credentials are stored only as encrypted secrets, all API traffic uses HTTPS, and access to the build system is limited to authorised staff.

10. Children

The app is an internal tool and does not collect data from children. Our videos are published as "not made for kids" educational content for college students.

11. Changes

We will post any changes on this page and update the date above.
