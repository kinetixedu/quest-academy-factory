# Ep 17 - Stones and Bricks - notes

## Facts (verified)
- IS 1077 : 1992 "Common Burnt Clay Building Bricks - Specification": modular size 190 x 90 x 90 mm (also 190 x 90 x 40); classes 3.5 to 35 by average compressive strength (N/mm2); water absorption "not more than 20 percent by weight up to class 12.5 and 15 percent by weight for higher classes"; efflorescence "not more than 'moderate' up to class 12.5 and 'slight' for higher classes". Source (primary text): https://law.resource.org/pub/in/bis/S03/is.1077.1992.pdf ; summary https://infralens.in/code/IS-1077-1992
- CAUTION: BIS published IS 1077 : 2025 (13 Nov 2025), superseding IS 1077 : 1992 (https://shop.standards.ie/en-ie/standards/is-1077-2025-190450_saig_bis_bis_3756837). Its values could not be read online, so the script names NO code number for bricks; it voices only "the limit is twenty" for a class-10 brick (1992 value). Lead: confirm against IS 1077 : 2025 before final, or keep the code off screen.
- IS 3495 (Parts 1-4) : 1992 test methods: compressive strength (soak, fill frog flush with cement mortar (ratio not legible online, not voiced), cure under damp sacking 24 h then 3 days in water, load at 14 N/mm2 per minute); water absorption (oven dry 105-115 C, immerse at 27 +/- 2 C for 24 h, absorption = (M2 - M1)/M1 x 100); efflorescence (ends in 25 mm water in a dish, dry out, repeat, rate nil / slight (<=10 %) / moderate (<=50 %) / heavy (>50 %) / serious (powdering or flaking)). Source: https://law.resource.org/pub/in/bis/S03/is.3495.1-4.1992.pdf . Note Part 2 was revised as IS 3495 (Part 2) : 2019 (https://www.services.bis.gov.in/php/BIS_2.0/bisconnect/knowyourstandards/Indian_standards/isdetails/MjQ0ODg=), so the script names no IS 3495 year either.
- Field tests: two bricks struck together give a clear ringing sound; fingernail scratch leaves no mark; dropped from about 0.9-1.0 m onto hard ground it should not break; uniform colour, sharp corners. Source: RGPV notes https://www.rgpv.ac.in/campus/CE/3%20I%20BCE%20I%20BT-204%20I%20Bricks%20I%20Classification%20I%20Properties%20I%20Tests%20I%20Uses.pdf
- Geological classification: igneous (granite, trap), sedimentary (sandstone, limestone), metamorphic (marble from limestone, quartzite from sandstone, slate from mudstone); hard unstratified granite preferred for foundations. Source: https://www.rcet.org.in/uploads/academics/regulation2024/rohini_44881882483.pdf
- Indus bricks: uniform sizes in the 1:2:4 thickness:width:length ratio; fired brick used from about 3000 BC (Kalibangan). Source: https://en.wikipedia.org/wiki/Brick (script voices only the ratio).

## Process to animate (M0-M9, B1-B2)
1. Brick pile; Raghu face + two bricks clink (ring wave rings out, chip "FIELD TEST 1 RING").
2. Fingernail scratch - surface shows no mark (tick).
3. Drop from 1 m: height ruler, brick falls, lands whole (tick).
4. Lab: oven -> scale reads 3.00 kg (chip DRY).
5. Water tank, 24-hour clock spins; brick out, wiped, scale reads 3.45 kg (chip WET).
6. Counter: 3.45 - 3.00 = 0.45 kg; 0.45 / 3.00 x 100 = 15 % ; bar against a 20 % limit line (green, passes).
7. Press: load counter runs 0 -> 171 kN, crack lines appear; face 190 x 90 = 17,100 mm2; 171,000 N / 17,100 mm2 = 10.0 N/mm2 (chip CLASS 10).
8. Efflorescence dish: brick in 25 mm water, water level drops twice, white patches bloom; rating dial nil -> serious, needle stops at "slight".
9. Rock cards: igneous / sedimentary / metamorphic with granite, sandstone, marble; granite slides into the plinth of the section drawing from Ep 16.

## Numbers (EXAMPLE FIGURES: brick masses 3.00 / 3.45 kg, 171 kN, rejected batch 24 %, quiz 2.0 / 2.4 kg)
- (3.45 - 3.00) / 3.00 x 100 = 15.0 % (passes 20 %).
- 190 x 90 = 17,100 mm2; 171,000 / 17,100 = 10.0 N/mm2 (class 10, so the 20 % limit applies).
- Quiz: (2.4 - 2.0) / 2.0 x 100 = 20 % -> "not more than 20 %" -> passes, at the limit.
- X5: 24 % > 20 % -> rejected.
