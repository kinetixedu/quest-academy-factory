H5|0.65|Every box is a subset of his three snacks. And the set of all those subsets has a name. The power set.
P1|0.35|First, a quick recall. A subset of A is a set whose every element is also in A.
P2|0.4|The power set of A is the set of all the subsets of A. We write it P of A.
P3|0.6|One note. The current NCERT book no longer has this topic, but the JEE Main syllabus still lists it. So we learn it properly.
L1|0.4|Now let us build every box, one snack at a time.
L2|0.4|Start with no snacks. There is only one box: the empty one.
L3|0.4|Add the samosa. Each box can now go two ways: without it, or with it. One box becomes two.
L4|0.4|Add the banana. Again, every box splits in two. Two becomes four.
L5|0.65|Add the laddoo. Four becomes eight. Each snack doubles the count.
L6|0.65|So three snacks give two times two times two. Eight different tiffin boxes, and one of them is empty.
D1|0.4|Why does this always work?
D2|0.75|Step one. Every element faces one yes or no question: is it in this subset, or not?
D3|0.75|Step two. The choices do not affect each other. So each new element doubles the number of subsets.
D4|0.75|Step three. With n elements, that is two, multiplied by itself n times.
D5|0.65|So if A has n elements, P of A has two to the power n elements.
K1|0.4|Side by side. A has three elements: the samosa, the banana and the laddoo.
K2|0.6|P of A has eight elements, and every one of them is a set. The empty set, three sets of one snack, three pairs, and the full box.
K3|3.2|Pause and think. What is the power set of the empty set? Is it empty?
K4|0.65|Not empty! The empty set has one subset, itself. So P of phi has one element, phi. Two to the power zero is one.
T1|0.7|Remember this. The power set holds every subset. A set with n elements has two to the power n subsets.
W1|0.35|Now, one worked example.
