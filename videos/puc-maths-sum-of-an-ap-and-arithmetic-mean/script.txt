P1|0.4|First, a quick reminder. An arithmetic progression, or A P, is a list where you add the same number every time.
P2|0.4|Like saving twenty rupees every week. Twenty, forty, sixty, eighty.
P3|0.4|The first term is called a. The number you keep adding is called d, the common difference.
P4|0.6|To reach the tenth term, you add d only nine times. So the n th term is a, plus n minus one times d.
P5|0.6|One note. Class 10 teaches this sum, so the current Class 11 NCERT text skips it. JEE Main still asks it.
G1|0.4|Now the trick. Write the sum forwards. One, plus two, plus three, all the way to one hundred.
G2|0.4|Then write it again, backwards, right under it. One hundred, plus ninety nine, down to one.
G3|0.4|Now add each column. One plus one hundred is one hundred and one. Two plus ninety nine, again one hundred and one.
G4|0.4|Every column gives one hundred and one, and there are one hundred columns.
G5|0.4|So two copies make one hundred times one hundred and one. Ten thousand one hundred.
G6|0.65|One copy is half of that. Five thousand and fifty.
L1|0.4|Here is the same trick as a picture. Build a staircase of blocks. One block, then two, then three.

L3|0.4|The rectangle is n blocks wide and n plus one blocks tall. Watch n grow.
L4|0.65|Whatever n is, one staircase is exactly half the rectangle. So the sum is n times n plus one, over two.
D1|0.4|Now any A P. We call its sum S n, the sum of the first n terms. Its last term is called l.
D2|0.75|Step one. Write S n forwards. a, then a plus d, and so on, up to l.
D3|0.75|Step two. Write it backwards. l, then l minus d, and so on, down to a.
D4|0.75|Step three. Add the two lines. Each column gives a plus l, because one term goes up by d while the other goes down by d.
D5|0.75|Step four. There are n columns. So two S n equals n times, a plus l.
D6|0.75|Step five. Divide by two. S n equals n over two, times a plus l.
D7|0.75|And l is a plus n minus one times d. Put that in, and S n equals n over two, times two a, plus n minus one d.
