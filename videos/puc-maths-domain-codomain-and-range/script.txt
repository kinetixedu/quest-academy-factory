P1|0.35|Quick recall. A function sends every element of one set to exactly one element of another set.
P2|0.4|We write f, from A to B. A is where the inputs come from. B is where the outputs land.
P3|0.4|The domain is the set A. It holds every input the function takes.
P4|0.4|The codomain is the set B. It holds every output the function is allowed to give.
P5|0.65|The range is the set of outputs the function actually gives. These outputs are called images.
M1|0.4|Watch one run. A is one, two, three, four. B is the numbers from one to eight. The rule is f of x equals two x.
M2|0.4|One goes to two. Two goes to four. Three goes to six. Four goes to eight.
M3|0.4|Every input got exactly one arrow. So the whole of A is the domain.
M4|0.4|Now look at B. Two, four, six and eight are hit. One, three, five and seven are never hit.
M5|0.65|So the range is two, four, six, eight. It sits inside the codomain, but it is smaller.
I1|0.75|Two words you will meet in every exam. f of three is six. So six is the image of three, and three is the preimage of six.
I2|0.65|Every element of the domain has exactly one image. But an element of the codomain can have no preimage at all, like five.
K1|0.4|Side by side. The codomain is chosen when we write the function: the allowed outputs, like marks from zero to one hundred.
K2|0.4|The range is found by running the function: the outputs that really appear, like forty one to ninety six.
K3|0.6|So the range is always a subset of the codomain. They can be equal, but the range can never be bigger.
K4|3.2|Now you try. f goes from N to N, and f of x equals two x. Is the range the whole of N? Pause and decide.
K5|0.65|No! The outputs are two, four, six, and so on. Odd numbers are never hit, so the range is only the even natural numbers.
T1|0.7|Remember this. The codomain is what is allowed. The range is what actually happens.
