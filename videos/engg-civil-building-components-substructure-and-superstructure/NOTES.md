# Ep 02 - Building Components - Substructure and Superstructure - notes

## Facts used
- Substructure = below ground floor (plinth) level, in contact with soil; superstructure = above it. Components (PCC bed, footing, plinth, plinth beam, columns, beams, slab, walls, lintel, sunshade, stairs, parapet). Standard building construction text content, no code named.
- Load path slab -> beam -> column -> footing -> soil: standard structural concept.
- Differential settlement causes diagonal cracks at door/window corners: standard building pathology.
- Tower of Pisa: began to sink when construction reached the second floor in 1178; foundation only about 3 m deep in weak, unstable subsoil. https://en.wikipedia.org/wiki/Leaning_Tower_of_Pisa
- No IS code named. No numbers that need the EXAMPLE FIGURES chip (no illustrative values).
